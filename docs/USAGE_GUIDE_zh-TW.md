# 團膳廚房系統 · 使用與交接指南

> 給「人」看的操作手冊（不是給 AI 代理的規格）。一頁看懂：每天怎麼用、系統幫你做什麼、接手前要設定什麼。
> 其餘 `docs/FEATURE_*`、`CURRENT_SSOT.md` 是開發歷程與規格；本檔只講「怎麼用」。
>
> **最重要的原則**：系統給的每個數字（配額、菜色、良率、排程時間）都能當場改。它是助手，不是老闆。

---

## 1. 這套系統在幫你解決什麼

把「排菜單 → 備料 → 採購 → 製程排班」這條每天都要跑一次的鏈子自動接起來。
你輸入今天要出的菜與人數，系統往下推：要備多少料、庫存夠不夠、缺的要買多少、幾點開工才來得及。

同時盯著三件事：

- **別浪費食材（惜食）** — 快過期的優先用，來不及就加工延壽
- **菜色要均衡** — 主菜／主食／蔬菜／湯自動湊齊
- **看得懂的重量單位** — kg／台斤／磅一鍵切換

---

## 2. 每天怎麼用（三步，全部從首頁「今日開工」開始）

### 步驟 1 — 今日開工（首頁 `/`）
- 手動選菜，或用**成本／庫存排序建議**挑
- **一鍵均衡菜單**：自動湊主菜 1・主食 1・蔬菜 2・湯 1（配額可改）
- 會提示「快過期的先用」「可加工延壽」
- 按下去，下面整條鏈子自動生成草稿

按一次「今日開工」，會一起生出這五樣（每一樣都是可編輯草稿）：

```
菜單 → 備料快照 → 採購需求草稿 → 製程規劃＋任務 → 排程建議
```

### 步驟 2 — 買與存（`/purchase`、`/inventory`、`/market-prices`）
- 採購單走 **草稿 → 待收 → 已收貨**
- 收貨自動回補庫存，不用手動改數字
- 市場行情頁比對今日蔬果批發價

### 步驟 3 — 菜與食材（`/recipes`、`/ingredients-master`、`/menu-import`）
- 配方 BOM（每道菜用哪些料、多少）
- 食材主檔（單位、成本、耗損係數）
- **拍照 OCR** 直接把手寫菜單匯入

## 3. 四條要記住的規則

1. **重量：存 kg，顯示隨你切**
   資料庫永遠存公斤。右上角一鍵切 `kg / 台斤 / 磅`，全站顯示（含單價 $/單位）當場換算、再按換回——像翻譯器。
   `1 台斤 = 0.6 kg`、`1 磅 = 0.453592 kg`。

2. **惜食：快過期的優先用**
   系統會把接近保存期的食材推到前面（清庫存料理建議）。真的來不及，就**加工延壽**（例如煮熟冷藏）變成新批次，仍留在推薦迴圈裡，不憑空消失。

3. **庫存數字只走交易**
   扣料、回補、盤點調整都經過交易寫入並留稽核紀錄；批次剩餘量用 FEFO（先到期先出）同步。不會有人直接手改庫存數字。

4. **建議都能覆寫**
   均衡配額、推薦菜色、加工良率、排程開工時間——全部給的是預設值，畫面上就能改。

## 4. 接手前的一次性設定

> 從 `catering-system/` 執行；種子腳本都先 dry-run 看結果，再加 `--execute` 寫入。
> 腳本需要 `.env` 裡的 Firebase 變數。

1. **部署 Firestore 規則** ✓ 已完成
   之後若改了食材／配方欄位白名單，記得重新部署 `firestore.rules`。
2. **種子：核心食材**（冪等，可重跑）
   ```bash
   npx tsx scripts/seedIngredients.ts
   ```
3. **種子：加工延壽良率**（merge-only、乾貨略過）
   ```bash
   npx tsx scripts/seedPreservationYields.ts --execute
   ```
4. **種子：初始批次**（讓保鮮系統看見既有庫存）
   ```bash
   npx tsx scripts/seedInitialBatches.ts --execute
   ```
5. **種子：菜色類別**（供均衡檢查用；猜不出的略過，之後手動補）
   ```bash
   npx tsx scripts/seedDishCategories.ts --execute
   ```
6. **設定食材保存天數**
   在食材主檔填上保存天數，保鮮警示與惜食推薦才會運作。

## 導覽小抄

左側選單分三群：

- **每天用這裡**：首頁 `/`、今日營運 `/daily-ops`、週計畫 `/week-plan`
- **菜與食材**：配方 `/recipes`、食材主檔 `/ingredients-master`、菜單匯入 `/menu-import`
- **買與存**：採購 `/purchase`、庫存 `/inventory`、市場行情 `/market-prices`

更細的鏈子頁面收在「進階功能」群組；排程參數在「廚房設定」`/kitchen-settings`。

> 內部所有重量以 kg 儲存與計算，畫面顯示單位僅為呈現。系統建議一律可手動覆寫。
